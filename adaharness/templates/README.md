# AdaHarness Project Files

This directory is generated by `adaharness init`.

Start with the bundled example as an installation smoke test:

```bash
adaharness analyze \
  --traces .adaharness/traces/overconstrained_harness.jsonl \
  --current-policy .adaharness/policies/current-policy.json \
  --diagnostics-config .adaharness/diagnostics/default.toml \
  --out .adaharness/reports/harness-drift.md
```

Then replace the example trace with JSONL events from your own agent runs:
existing tests, benchmark scripts, manual QA scripts, staging jobs, or log
exports. AdaHarness analyzes trace events only; it does not run your agent,
provider, tools, or runtime.
