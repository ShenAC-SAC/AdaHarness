# AdaHarness Project Files

This directory is generated by `adaharness init`.

Start with the bundled example:

```bash
adaharness analyze \
  --traces .adaharness/traces/overconstrained_harness.jsonl \
  --current-policy .adaharness/policies/current-policy.json \
  --diagnostics-config .adaharness/diagnostics/default.toml \
  --out .adaharness/reports/harness-drift.md
```

Then replace the example trace with JSONL events exported by your own agent
evals. AdaHarness analyzes trace events only; it does not run your agent,
provider, tools, or runtime.
