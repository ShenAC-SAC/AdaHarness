# AdaHarness Project Files

This directory is generated by `adaharness init`.

Use `capture` to run your own single-task agent entrypoint and create traces:

```bash
adaharness capture \
  --tasks .adaharness/tasks/sample-tasks.jsonl \
  --out .adaharness/traces/run.jsonl \
  --analyze-out .adaharness/reports/harness-drift.md \
  --current-policy .adaharness/policies/current-policy.json \
  --diagnostics-config .adaharness/diagnostics/default.toml \
  -- python your_agent.py --prompt "{prompt}"
```

The command after `--` is your agent's existing one-task entrypoint. Task fields
such as `{prompt}` are replaced from the JSONL task row.

You can also start with the bundled trace example as an installation smoke test:

```bash
adaharness analyze \
  --traces .adaharness/traces/overconstrained_harness.jsonl \
  --current-policy .adaharness/policies/current-policy.json \
  --diagnostics-config .adaharness/diagnostics/default.toml \
  --out .adaharness/reports/harness-drift.md
```

The bundled example proves the analyzer works; it does not diagnose your agent.
